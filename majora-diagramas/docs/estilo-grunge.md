# Estilo Grunge

Referencia de estilo para los diagramas y el video. Es el estilo obligatorio del proyecto.

## Paleta

| Uso | Color | Hex |
| --- | --- | --- |
| Fondo | Negro | `#0d0d0d` |
| Superficies | Carbón | `#1a1a1a` |
| Estado DORMIDA, textos secundarios | Gris | `#8a8a8a` |
| Estado CALMA, flechas | Gris claro | `#c9c9c9` |
| Estado DESPERTAR, títulos, acentos | Naranja | `#ff6a00` |
| Estado POSESIÓN, alertas, fallas | Rojo | `#c1121f` |
| Texto principal | Hueso | `#ece8e1` |

El color comunica el estado: gris = inactiva, naranja = alerta, rojo = amenaza.

## Tipografía

Titulares en Impact (alternativa Arial Black), mayúsculas. Datos y etiquetas en Courier New (monoespaciada).

## Textura

- Bordes irregulares: desplazamiento con turbulencia (SVG `feDisplacementMap`) o `roughness: 2` en Excalidraw.
- Ruido de película sobre el fondo a baja opacidad.
- Cinta o franja diagonal naranja como acento.
- Trazos gruesos (3–4 px) y trazos discontinuos para rutas de falla.
